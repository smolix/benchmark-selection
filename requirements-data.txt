# Environment for data/build_cost_tables.py.  Use a venv of its own: these
# pins conflict with requirements.txt (numpy, pandas), so installing them
# into ~/venvs/benchselect would silently change the experiment
# environment.  Matches ~/venvs/mteb on 4090-2.maas (uv pip freeze,
# 2026-10-17), except that torch is the CPU build and its CUDA-only
# dependencies (cuda-*, nvidia-*, triton) are left out: mteb imports torch,
# but the script only reads task metadata and never runs a model.
#
#   uv venv -p 3.12 ~/venvs/mteb
#   uv pip install --python ~/venvs/mteb/bin/python --torch-backend cpu \
#       -r requirements-data.txt
#
# or with pip, installing the CPU torch wheel first (the PyPI torch wheel
# pulls in the CUDA 13 runtime, several GB, on Linux x86_64):
#
#   python3.12 -m venv ~/venvs/mteb
#   ~/venvs/mteb/bin/pip install torch==2.13.0 \
#       --index-url https://download.pytorch.org/whl/cpu
#   ~/venvs/mteb/bin/pip install -r requirements-data.txt
#
# python==3.12   (validated with 3.12.3 on Linux x86_64)
#
# The tables depend only on mteb (the task statistics ship inside the
# package) and on the cais/mmlu revision pinned in the script; the other
# pins lock the validated environment.
